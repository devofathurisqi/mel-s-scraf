# Working prompt / design brief

Build a complete, professional mobile-first reseller storefront for Mel’s Scraf, part of VuyamaLabs' catalog service for the Vuyama reseller community. Understand the existing commerce implementation before making changes. Brand direction: soft lavender, warm off-white, dark plum type and restrained butterfly accents inspired by the supplied logo; romantic serif typography, layered editorial imagery, flowing section rhythms.

Use the attached original logo. Preserve real product photos and garment colors. Make every section useful: discover, compare, select a shade, save, add to bag, and prepare an accurate order. Respect the exact tagline: Softly Wrapped, Beautifully You.

Show the full audited supplier catalog. Set every verified price from the Ecer column. Never inherit Sugar Shawl selling-price overrides. Unknown Ecer values must remain null and explicitly request confirmation.

No invented reviews, availability, shipping promises, or contact numbers. Isolate storage and brand configuration. Write readable source and a self-contained README. Check production build, routes, local images, quantities, subtotal, exact shade, share/checkout message, persistence, mobile layouts, filters, keyboard focus, and reduced motion. Review the actual rendered pages and repair observed problems before committing. Push only to the user-specified repository.
